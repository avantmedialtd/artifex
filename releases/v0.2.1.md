af v0.2.1

Answer "what's still outstanding on this PR?" in a single command.

## ✨ Highlights

- **Filter Bitbucket PR comments and tasks by resolution state** — `af bb pr comment list <id>` and `af bb pr task list <id>` now accept `--resolved` / `--unresolved` (mutually exclusive). For comments, resolution is a thread property, so the filter keeps or drops whole threads by their root's state with the reply tree intact; tasks match per-task state. The filter runs before rendering, so `--json` emits the filtered set too — scriptable for "show me only the open threads."

---

npm install -g @avantmedia/af      # new install
npm update  -g @avantmedia/af      # upgrade
