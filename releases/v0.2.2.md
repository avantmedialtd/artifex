af v0.2.2

See every pull request you have open, wherever it lives.

## ✨ Highlights

- **`af bb pr mine` — your authored PRs across every workspace** — one command answers "what have I got open?" without naming a repository or standing in one. It resolves your account, walks every workspace you belong to, and merges the results newest-updated first with a **Repo** column so ids are unambiguous. `--state` accepts the full set (`OPEN`/`MERGED`/`DECLINED`/`SUPERSEDED`/`ALL`), `--limit N` caps the list and stops paging early, `--workspace W` narrows the search when you want just one, and `--json` emits a flat array for scripting. A workspace your token can't read is skipped with a warning on stderr rather than failing the whole command, so one restricted workspace never hides the rest.

## 🩹 Fixes

- **`af bb pr list --state ALL` only returned open pull requests** — it omitted the `state` parameter entirely, and Bitbucket defaults to `OPEN` when none is sent, so "all states" quietly meant "open". Every state is now requested explicitly. Expect this command to return more rows than before. `SUPERSEDED` is also accepted and documented as a `--state` value.

## 🔧 Improvements

- **Dependencies refreshed across the board** — ink 7, TypeScript 7, vitest 5, cspell 10, oxlint 1.83, react 19.3 and bun 1.4, with `chalk` now declared explicitly instead of relying on a hoisted transitive of ink. Refreshed lock files clear all 32 outstanding audit advisories (17 in the CLI, 15 in the VS Code extension).
- **VS Code extension now requires VS Code 1.137 or newer** — the floor was raised so its `@types/vscode` can track the editor it actually targets. The extension ships through the Marketplace, so this does not affect the `af` CLI itself.
