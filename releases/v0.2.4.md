af v0.2.4

A maintenance release that keeps dependencies current. No commands or output changed.

## 🔧 Improvements

- **Updated `chalk` to 6.0.1**, the library behind `af`'s terminal colors.
- **Refreshed the development toolchain**: `vitest`, `oxlint`, `prettier`, `cspell` and the Node type definitions. These aren't installed with `af`, so this only matters if you work on `af` itself.

---

### Install

```bash
npm install -g @avantmedia/af      # new install
npm update  -g @avantmedia/af      # upgrade
```
